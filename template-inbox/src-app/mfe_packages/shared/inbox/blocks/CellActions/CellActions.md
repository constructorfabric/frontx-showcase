# CellActions

A table row's actions (kit icon `Button`s) at the end of their cell, `--space-1` apart. It stands in for an end alignment on a kit `DataTable` column, which the kit does not have.

- **Props**: content only: `children`.
- **Layout**: an end-aligned flex row. No visual declaration.
- **Used by**: `ContactsTable`.
- **Test**: `inbox-contacts-mfe/src/shared-inbox/blocks/CellActions.test.tsx`.
