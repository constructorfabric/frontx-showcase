# ActionRow

A wrapping row of actions.

## When to use

- Buttons under a card or a form, and screen-wide actions in a PageHeader.

## When not to use

- A group of buttons drawn as one control: use `ButtonGroup`.

## Props

`children` (the actions).

## Parts and layout

A wrapping flex row, gap `--space-2`; an action may shrink to the row's width on a phone.

## Replaces

`.actions` in the Hello World and Profile screens and the Widgets Host page.
