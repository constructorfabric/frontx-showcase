# TokenList

Token names in two columns.

## When to use

- The Current Theme screen's list of the token names it paints from.

## When not to use

- Values with labels: use a DescriptionList.

## Props

`tokens` (names such as `--primary`).

## Parts and layout

A two-column list of candidate `Text` on the mono role rendered as `code`.

## Replaces

The Current Theme screen's `.variables`.
