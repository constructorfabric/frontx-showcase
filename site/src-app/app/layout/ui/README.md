# Shell layout components

The named, reusable pieces of the shell's header and footer. `Header`, `Menu` and `Footer` hold the logic (screens, language, navigation through the screen domain) and compose these. The shell cannot import the site's blocks (template-site-blocks), so its chrome lives here under the same rules: built from kit components and the kit candidates (`@gears-frontx/kit-candidates`: `Link`, `Text`, `VisuallyHidden`), content-only props, stylesheets that lay out on tokens, and every other declaration a row of `../styles-exemptions.json` naming the kit gap or defect it waits for. Each piece is a candidate for design and the kit.

| Component | Props | Built from | Kit gap it fills |
| --- | --- | --- | --- |
| `HeaderBar` | `brand`, `nav`, `link` (`href`, `label`), `controls` | kit candidate `Link` | Sticky site header frame of the designer's V2 site: the lockup, then the navigation and the source link pushed to the end; from 900px down the navigation takes a second row, from 640px down the link is left out |
| `BrandLockup` | `href`, `label`, `company`, `product`, `badge`, `compact`, `onClick` | kit candidate `Link`, kit `Badge`, the brand template's logo (`@gears-frontx/site-brand/assets/constructor-weave.svg`) | The Constructor Fabric lockup as one link: logo, company name, divider, product wordmark with the blue X, and an optional badge right after the link, outside it, so its 10px label is not interactive text; `compact` is the footer's smaller size |
| `HeaderSelect` | `label`, `value`, `options`, `onChange` | kit `NativeSelect` | Compact header select with the arrow inset fixed for right-to-left text (the language select, shown only for a multilingual site) |
| `NavMenu`, `NavMenuItem` | `label`, children | kit `NavigationMenu` | Navigation bar with plain text links; from 900px down the entries stay on one row that scrolls sideways as on V2 when it outgrows the row, and a group's list opens under the whole header at the column's end, outside the scrolling row, so it is never clipped and stays within the viewport |
| `NavLink` | `href`, `active`, `label`, `onClick`, `grouped` | kit `NavigationMenuLink` | Navigation link: plain text, the active one in the link colour with a 2px underline |
| `NavGroup` | `label`, `active`, `closeKey`, children | kit `Collapsible` | A group of links behind a disclosure button, drawn as a dropdown; it closes after a choice, on Escape, on a click or focus outside and when `closeKey` (the mounted screen) changes. The kit NavigationMenu popup is not used for it because its focus guards fail axe `aria-hidden-focus` |
| `FooterFrame` | `brand`, children, `ink` | | Site footer frame: the lockup and one row of links, stacked and centred from 760px down |
| `FooterLinks`, `FooterLink` | `label`; `href`, `detail`, `external`, `onClick` | kit candidates `Text` (meta role), `Link`, `VisuallyHidden` | Labelled footer link list; `detail` is read out after a short visible label, `external` adds the Link's arrow and keeps the link in the same tab |
| `SkipLink` | `targetId`, `label` | | The page's first focusable element, off screen until focused; it moves focus to the element `targetId` names (the main landmark), since the screen's own content sits in a shadow root. A kit candidate of a later ui-kit pull request |

The brand's tokens and typeface reach the document through the shell's document-entry convention (`../../documentEntries.ts` loads every `src/document.css` an installed verify package delivers); on this site template-site-brand delivers them, once, in the document, and every shadow root renders in them.
