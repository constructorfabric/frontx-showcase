# PageFrame

One page of the catalogue: an `article` that stacks the page's blocks in one column at the page area's width.

## When to use

Around every page the catalogue's routes render (index, Examples, component, foundation, not found).

## Props

| Prop | Content |
|------|---------|
| `testId` | On the `article` |
| `children` | The page's blocks |

## Reproduces

The V2 showcase page column.
